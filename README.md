Temperature-Time-Series-Analysis

This project analyzes monthly global temperature anomalies from the HadCRUT5 dataset between 1850 and 2024.

The long-term temperature trend is analyzed using LASSO regression. Additionally, separate regressions are fitted for different time periods to illustrate changes in the temperature trend over time.

The time series is further analyzed using the ACF, PACF and Augmented Dickey-Fuller test. Seasonal differencing with a lag of 12 months is used to investigate stationarity.

Finally, an ARIMA model is fitted to the temperature data and evaluated using different forecast horizons.
